## 🚀 Introducing Code Rules!

Meet Code Rules, the package manager for engineering best practices. This first release lets you share rules across projects, customize them for each project, and generate guidance your coding agents can follow.

- **Write your own rules.** Set up a project with `code-rules project init`, then add project-only groups and rules.
- **Import shared rules.** Add rule libraries from Git, pin them to a version, and pick, exclude, or replace their rules.
- **Generate guidance, and check it in CI.** `code-rules project sync` builds guidance optimized for reading by your agents.
- **Publish your own libraries.** Create, validate, and share a rule library with `code-rules library`.
- **Install on macOS and Linux** with Homebrew or the [install script](https://code-rules.fabricahq.com/start-here/install/).

  ```sh
  brew install fabricahq/tap/code-rules
  ```

To get started, see the [Code Rules docs](https://code-rules.fabricahq.com).
