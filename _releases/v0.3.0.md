## ✨ New Features

### Code Rules now has a public package for reading Code Rules libraries

Third-party tools can now read a Code Rules library exactly as the Code Rules tool itself reads it. The new `github.com/fabricahq/code-rules/coderules` package parses library release tags and their release records, rule files, group metadata, and the canonical group list. (#94)

## ⬆️ Improvements

- The documentation now answers questions about a single rule's version: [where to find a rule's current version](https://code-rules.fabricahq.com/guides/version-rules/#find-a-rules-current-version), [how a rule gets a new version](https://code-rules.fabricahq.com/guides/version-rules/#how-a-rule-gets-a-new-version), and [how to update one rule in your project](https://code-rules.fabricahq.com/guides/update/#update-one-rule-to-its-newest-version). (#92)
