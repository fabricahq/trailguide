# Release notes

Release Planner's agent writes one `v<semver>.md` file here per release. The first is `v0.1.0.md`.

Edit the notes in the release PR and merge it to approve publication. The merged file becomes the GitHub release description. See [Make a release](https://release-planner.fabricahq.com/start-here/release/) for the procedure and the [release policy](../.release-planner/policy.md) for versions and this repository's release pipeline.
