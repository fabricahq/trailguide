# Small vector studies

These are new hand-drawn SVG concepts on a 16-unit grid, not traced versions of the earlier generated images.
The previous bitmap concepts are unchanged.

## Quiet

Closed cube with a 1.5 unit outline and 1.6 unit eye strokes.

## Pebble

Wider clipped shell; filled crescent eyes remove thin arch endpoints.

## Shelter

Open base removes the lower frame that competes with the expression.

## Glow

Solid silhouette with two large negative-space arches; no extra mouth.

All use the same geometry at every preview size so the small samples expose real limitations.
