The artwork itself is not deterministic.

## Shared prompt

Use case: logo-brand.
Create ONE original logo symbol for FABRICA, an umbrella brand of modular software tools for technical teams building their own software factories.
The user wants this round to depart radically from conventional tech logos in some directions.
Combine the three assigned idea ingredients into a COHERENT logo, not a collage of three objects.
Flat opaque BLACK artwork on genuinely transparent alpha background, transparent internal gaps.
Vector-like edges, absolutely no 3D, shading, gradients, textures, checkerboard pixels or background.
One symbol only, no text, names, labels or wordmarks.
Readable at 16px; use large simple shapes and bold negative spaces, no hairlines or intricate detail.
Center on square canvas; longest extent exactly about 78 percent of canvas, all edges visibly inside generous margins.
Avoid F monograms, medical crosses and generic AI sparkle stars.
