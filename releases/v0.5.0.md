## ✨ New Features

- Point a source's `ref` at a branch, such as `main`, to follow its newest commits. `trailguide project update` moves the source to the branch's latest commit, and Trail Guide warns when a library's rules or skills on that branch aren't in a library release yet. See [Update rules and skills](https://trailguide.fabricahq.com/guides/update/). (#144)
- Fork a skill from one of a library's sources into the library, or fork a skill your library curates into your project. Trail Guide records where the fork came from and later lists what the original changed, so you can bring those changes in. (#145)
- Start a new skill with `trailguide library add skill NAME` or `trailguide project add skill NAME`, which writes a draft `SKILL.md` for you to fill in. (#147)
- Take only the skills a library requires, or leave out its recommended skills, with a level in `skills.exclude`. (#148)
- A library's skill can use a skill the library curates from another repository, and projects that install it get the curated skill too. (#143)

## ⬆️ Improvements

- `trailguide project update --help` explains how skills update, and naming a skill as an update target tells you to update its source instead. (#146)
- The docs homepage plays a narrated tour of Trail Guide. (#137)
