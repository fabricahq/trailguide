## ✨ New Features

### See every rule's version with `project list rules`

- Before, finding which version, release, and commit a project held for each rule meant reading the lockfile or a generated library README. You can now list every rule with its source, version, pin, exclusion, and replacement, and tools written in Go, such as [Rulemart](https://rulemart.fabricahq.com), can now read the same view from a project's `config.yaml` and `lock.json` with the `trailguide/projectview` package. (#172)
- Learn more in [project list rules](https://trailguide.fabricahq.com/reference/cli/#project-list-rules) and [Read a project from a tool](https://trailguide.fabricahq.com/reference/provenance/#read-a-project-from-a-tool).

```sh
trailguide project list rules
```

## ⛓️‍💥 Breaking Changes

Because Trail Guide is in initial development and hasn't been publicly announced, we're not including upgrade instructions.

### Managed folders move under `.trailguide/_managed/`

Trail Guide now keeps vendored sources in `.trailguide/_managed/vendor/` and generated guidance in `.trailguide/_managed/generated/`, so the files you edit and the files Trail Guide writes are easy to tell apart. The first `project sync` migrates a project, and other commands refuse the old layout until then. The managed project guide, `.trailguide/README.md`, and the `AGENTS.md` section point to the new paths; build, sync, update, and init replace an older, unedited guide but refuse to overwrite one you edited. (#170)

### Libraries declare `library.schemaVersion`

Libraries now declare `library.schemaVersion: 1` instead of `library.formatVersion: 1`, and new library release tags record `schemaVersion` too. Trail Guide still reads library releases published with `formatVersion`. In the `trailguide` Go package, `UnsupportedLibraryFormatError` is now `UnsupportedLibrarySchemaError`, and release records report their version as `SchemaVersion`. (#171, #176)

### Generated library READMEs list only license terms

A source's generated README in `.trailguide/_managed/generated/libraries/` now lists only the library's license and retained notices. Its revision and rule versions are in `lock.json` and `project list rules`, and its skills are in `SKILLS.md`. (#174)
