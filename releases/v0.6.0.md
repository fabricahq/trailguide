## ✨ New Features

### Forked skills can take in their source's changes

- Before, bringing a source's changes into a forked skill meant copying them over by hand. `trailguide project update` now tells you whether the source's changes merge into your fork, and merges them for you, keeping your edits. (#156)
- When a change touches the same lines as your edits, the update lists the files to merge by hand instead.
- Learn more in [Merge a source's changes into a forked skill](https://trailguide.fabricahq.com/reference/cli/#merge-a-sources-changes-into-a-forked-skill).

```sh
trailguide project update --merge-fork fabrica:skills/build-feature
```

### Skills can set the text Codex shows

- A skill can now set its display name, short description, and default prompt with the `display-name`, `short-description`, and `default-prompt` metadata keys, which name no agent. Trail Guide writes them into the `agents/openai.yaml` file Codex reads, in the skill's `.agents/skills/` copy. (#157)
- A skill that ships its own `agents/openai.yaml`, for icons or other Codex settings, keeps it unchanged.
- Learn more in [Text agents show](https://trailguide.fabricahq.com/reference/skill-format/#text-agents-show).
