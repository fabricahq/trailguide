v0.6.0 is mostly for library authors and for tools that read libraries: a library can now list skills that install only as dependencies, and the `trailguide` Go package now reads a library's manifest.

## ✨ New Features

### Libraries can list skills that install only as dependencies

- Before, a skill a library had only because its other skills call it, such as a helper skill, was one more skill projects could choose on its own. A library can now list it in `library.skills.dependencies`, and projects install it only with the skills that use it. (#160)
- `"*"` and `recommended` never select a dependency, and a project that names one in `skills.include` gets a message naming the skills that call it.
- Learn more in [Dependencies](https://trailguide.fabricahq.com/reference/library-format/#dependencies).

### Tools can read a library's manifest with the Go package

- Before, a tool such as a catalog had to copy Trail Guide's parser to read a library's license and skill levels. The `github.com/fabricahq/trailguide/trailguide` package now reads a library's manifest, and places each library file in the library's repository, the same way Trail Guide does. (#161)
- It reads only what a library publishes, not the settings that configure the repository as a project.
- Learn more in [Read libraries from other tools](https://trailguide.fabricahq.com/reference/library-format/#read-libraries-from-other-tools).
