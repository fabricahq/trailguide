## ✨ New Features

### Libraries can list skills that install only as dependencies

- Before, a library might recommend a skill only because some other skill needed it as a dependency. This was problematic because we weren't actually recommending the skill, but we still needed consumers to download it. Now, a library can list a dependency skill in `library.skills.dependencies`, and projects install it only with the skills that use it. (#160)
- Learn more in [Dependencies](https://trailguide.fabricahq.com/reference/library-format/#dependencies).

### Trailguide's parse is now public

- Before, a site like [Rulemart](https://rulemart.fabricahq.com) had to copy Trail Guide's parser to read a library's license and skill levels. The `github.com/fabricahq/trailguide/trailguide` package now reads a library's manifest, and places each library file in the library's repository, the same way Trail Guide does. (#161)
- Learn more in [Read libraries from other tools](https://trailguide.fabricahq.com/reference/library-format/#read-libraries-from-other-tools).
